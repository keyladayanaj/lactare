# Lactare — Front-end organizado

## Estrutura
- `index.html` — entrada do projeto.
- `pages/login/` — login da doadora, rede de apoio e equipe.
- `pages/cadastro/` — cadastro da doadora, cadastro da família e sucesso.
- `pages/perfis/` — telas pós-login da Nutriz e do Apoio.
- `pages/dashboard/` — dashboard da equipe.
- `assets/css/style.css` — CSS compartilhado.
- `assets/js/script.js` — JavaScript compartilhado.
- `assets/images/lactare-logo.png` — logo.

## Fluxo
Doadora → Perfil Nutriz | Rede de Apoio/Família → Perfil Apoio | Equipe → Dashboard.


CSS dos perfis separado por tela:
- assets/css/perfil-apoio.css
- assets/css/perfil-nutriz.css

O style.css continua como CSS geral; os logins existentes não foram alterados.
